# 围棋游戏 - Go Game

一个功能完整的围棋游戏，支持人机对战，具备多种难度选择和丰富的辅助功能。

## 功能特性

### 核心游戏功能
- ✅ 标准19x19棋盘
- ✅ 黑白双方轮流落子
- ✅ 吃子规则和打劫检测
- ✅ 禁着点检测

### AI对手
- **初级AI (EasyAI)**: 基于简单启发式规则，适合新手
- **中级AI (MediumAI)**: 基于Minimax搜索算法，有一定挑战性
- **高级AI (HardAI)**: 基于蒙特卡洛树搜索(MCTS)，响应时间<10秒

### 辅助功能
- **高胜率点提示**: 显示AI推荐的最佳落子位置，可开关
- **势力图**: 半透明显示黑白双方的势力范围，可开关
- **悔棋**: 可连续悔棋多步
- **保存/加载**: 保存和读取游戏进度
- **重新开始**: 重置游戏，保留难度设置
- **PASS**: 跳过当前回合

### 终局判定
- 双方连续PASS进入终局
- 简单的点目算法
- 黑贴7.5目
- 显示最终胜负结果

### 实时形势判断
- 基于当前局面估算胜率
- 估算双方目数
- 实时显示在界面上

### UI特点
- 简洁美观的界面设计
- 流畅的游戏体验
- 清晰的状态显示
- 直观的按钮操作

## 安装和运行

### 环境要求
- Python 3.7+
- Pygame 2.5.0+

### 安装步骤

1. 克隆或下载项目
```bash
cd c:\games\go
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

3. 运行游戏
```bash
python main.py
```

## 游戏说明

### 基本操作
- **黑方**: 玩家执黑先行，点击棋盘落子
- **白方**: AI执白应对
- **PASS按钮**: 跳过当前回合
- **悔棋按钮**: 撤销上一步（同时撤销黑白双方各一步）

### 难度选择
- **初级**: 适合围棋新手
- **中级**: 有一定基础的玩家
- **高级**: 挑战模式，响应时间稍长

### 辅助功能
- **提示按钮**: 开关高胜率点提示（只在玩家回合显示）
- **势力图按钮**: 开关势力图显示
- **保存/读取**: 保存和加载游戏进度
- **重新开始**: 重置游戏

### 终局
当双方连续PASS后，游戏进入终局，会自动计算最终目数并显示胜负结果。

## AI技术说明

### 初级AI (EasyAI)
- 基于启发式规则
- 优先选择能吃子或防守的位置
- 考虑星位等开局要点
- 快速响应

### 中级AI (MediumAI)
- Minimax搜索算法
- 3层深度搜索
- 局面评估函数
- 候选走法筛选

### 高级AI (HardAI)
- 蒙特卡洛树搜索(MCTS)
- 树策略：UCT公式
- 模拟策略：随机走子
- 8秒时间限制
